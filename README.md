# DQWマイ攻略室

ドラゴンクエストウォークの個人用記録アプリです。サーバーやアカウント登録は不要で、ブラウザだけで動きます。

## 起動方法（Windows）

1. このフォルダーをエクスプローラーで開きます。
2. `index.html` をダブルクリックします。Chrome、Edge、またはSafari（Macの場合）で開きます。
3. インターネット接続なしでも使えます。外部サービスへの通信はありません。

## 操作方法

- **パーティ編成**：4人それぞれの職業を選び、武器・かぶと・盾・よろい上・よろい下を記録できます。武器の用途や評価メモ、防具の補足メモも保存されます。入力内容は自動保存されます。
- **レベル上げ装備アドバイザー**：対象職業、目的、重視することを選び、武器の特徴・レベル・限界突破・スキル・手動のMP効率評価を登録して比較できます。パーティ登録済みの職業や武器名をアドバイザー側へコピーできます。コピー先を編集しても、パーティ編成は変更されません。
- **経験値記録**：日付、時間（分）、獲得経験値を入力します。経験値／分が自動で表示されます。「記録を追加」で履歴に保存します。不要な履歴は「×」で削除できます。
- **バックアップ**：「JSONを書き出す」で記録をファイルに保存できます。「JSONを読み込む」で復元できます。読み込みは現在の記録を置き換えるため、確認メッセージが表示されます。

### アドバイザーの評価について

武器性能の自動取得やゲーム内ダメージ計算は行いません。武器名から性能を推測せず、登録した「全体攻撃」「メタル系特効」と手動で付けたMP効率評価だけを、表示される簡易基準に沿って比較します。武器レベル、限界突破、スキル名、職業は記録・説明用で、職業ごとの適性や実ダメージの評価には使いません。情報が足りない場合は、結果に不足項目と比較していない情報を表示します。経験値の獲得量や経験値／分を予測する機能ではありません。

登録武器は最大100件です。武器を登録・編集すると、このブラウザーに自動保存され、JSONバックアップにも含まれます。古いJSONにアドバイザーデータがない場合は、アドバイザー欄だけ初期状態になり、既存のパーティ・経験値記録は引き継ぎます。

## 保存について

入力データは、使っているブラウザのこの端末内に保存されます。同じブラウザで開くと続きから使えます。ブラウザのデータを消去したり、別の端末・ブラウザを使ったりするとデータは共有されません。定期的にJSONを書き出して保管してください。

公開後は、保存先が公開サイトのURL（オリジン）に切り替わるため、今までパソコンで使っていたローカル版の記録は自動では移りません。公開前にローカル版でJSONを書き出し、公開サイトを開いた後にそのJSONを読み込むと引き継げます。パソコンとiPhoneの間も自動同期しないため、必要に応じてJSONで移してください。

## GitHub Pagesで公開する手順（この手順はまだ実行していません）

このアプリはHTML・CSS・JavaScriptだけでできており、ビルドやサーバー用プログラムは不要です。GitHub Pagesは静的ファイルを公開できるので、現在の構成のままで使えます。HTMLからCSSとJavaScriptを相対パスで読み込んでいるため、GitHub Pagesのプロジェクト用URLでも参照できます。

公開前に知っておくこと：

- GitHub Pagesのサイトはインターネット上で公開されます。リポジトリやアプリのファイルを第三者が見られる状態になるため、個人情報やパスワードをファイルに書かないでください。
- アプリの編成・経験値記録はリポジトリへ送信されず、各自が使うブラウザ内に保存されます。GitHub Pagesへのアクセスでは、GitHubがセキュリティ目的で訪問者のIPアドレスを記録します。
- GitHub FreeではPagesを使うリポジトリは公開設定が必要です。公開リポジトリを作る前に、ソースファイルに秘密情報が含まれないことを確認してください。

公開する場合の手順：

1. ローカル版の「JSONを書き出す」で、必要な記録をバックアップします。
2. GitHubにサインインし、新しい公開リポジトリを作成します（例：`dqw-my-strategy`）。この段階でリポジトリの中身は公開されます。
3. リポジトリのトップ階層に `index.html`、`styles.css`、`app.js`、`README.md` をアップロードして保存します。既存の秘密情報やバックアップJSONはアップロードしません。
4. リポジトリの **Settings → Pages** を開き、**Build and deployment** の **Source** で **Deploy from a branch** を選びます。
5. ブランチに `main`、フォルダーに `/(root)` を選んで **Save** を押します。
6. Pages設定画面に表示されるURLを開いて確認します。公開反映まで数分かかることがあります。
7. 公開URLをiPhoneのSafariで開き、必要ならJSONバックアップを読み込みます。Safariの共有メニューから「ホーム画面に追加」すると、次回から開きやすくなります。

GitHubの最新手順は[GitHub Pages クイックスタート](https://docs.github.com/en/pages/quickstart)と[公開元の設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)を参照してください。

## ファイル

- `index.html`：画面の内容
- `styles.css`：レイアウトとスマートフォン対応
- `app.js`：保存、計算、バックアップの処理
